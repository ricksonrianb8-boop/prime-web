# Portfólio — Rikcson Rian

Projeto pessoal feito com HTML, CSS e JavaScript.

## Abrir no VS Code
1. Extraia o ZIP.
2. Abra a pasta `portfolio-rikcson` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Arquivos
- `index.html`: estrutura do site.
- `style.css`: visual, tema claro e responsividade.
- `script.js`: botão de tema, menu ativo e ano automático.

## Antes de publicar
- Confira links, e-mail e certificados.
- Coloque o currículo em PDF na pasta `assets` com o nome `curriculo.pdf`, ou altere/remova o botão.
- Teste em computador e celular.

## GitHub Pages
Envie os arquivos ao repositório. Depois abra Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)` e salve.
